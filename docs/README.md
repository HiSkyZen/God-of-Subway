# 문서 인덱스

이 디렉터리는 현재 Bun/TypeScript 구현의 기준 문서입니다.

- [`ARCHITECTURE.md`](ARCHITECTURE.md): 서버, 클라이언트, 엔진, 데이터 흐름과 모듈 경계
- [`TRANSFERS.md`](TRANSFERS.md): 환승시간, 동명이의역, 공용선로, 제자리 환승, 혼잡 가중치
- [`RAPID_SERVICE.md`](RAPID_SERVICE.md): 급행 운행 노선과 급행↔완행 후보 생성 방식
- [`DEVELOPMENT.md`](DEVELOPMENT.md): 로컬 개발, 데이터 감사, 테스트
- [`gtx-a-timetable-source.md`](gtx-a-timetable-source.md): GTX-A 북부/남부 데이터 정책
- [`realtime-progress-design.md`](realtime-progress-design.md): 실시간 여정 진행 상태와 fallback

루트의 `CONTINUOUS_OPERATION_NOTES.md`, `EXPERIMENT_GUIDE.md`, `VERCEL_DEPLOY.md`는 각각 운영, 실험 기록, 배포 문서입니다.
