# 급행 운행 로직

## 지원 노선

2026-08 웹 검증 기준 수도권 전철에서 정기 급행 운행을 갖는 지원 노선은 다음 6개입니다.

- 1호선
- 4호선
- 9호선
- 경의중앙선
- 수인분당선
- 경춘선

## 서비스 판별

`src/engine/rapid-service.ts`는 열차 `service` 문자열의 `급행/특급/express/rapid/직통` 표기와 정차 패턴(`stop.call === false`)을 함께 사용합니다. 단순 노선명만으로 급행을 가정하지 않습니다.

## 급행↔완행 환승 후보

기본 그래프 후보를 만든 뒤 급행 운영 노선의 각 구간에서 실제 시간표를 조회합니다. 중간역 전후에 `rapid`와 `local` 서비스 조합이 존재하면 동일 노선 2개 세그먼트로 분할한 0초 제자리 환승 후보를 추가합니다. 후보 생성 자체가 추천을 확정하지 않으며, 최종 ETA 계산이 전체 여정 도착시각을 비교하여 이득이 있는 후보만 선택합니다.

이 방식으로 급행 미정차역에서 억지로 갈아타는 경로를 만들지 않고, 급행이 실제로 정차하는 역의 시간표를 기준으로 판단합니다. 예를 들어 4호선 급행이 한대앞에 정차하지 않는 현재 패턴도 시간표 조회에서 자연스럽게 제외됩니다.
